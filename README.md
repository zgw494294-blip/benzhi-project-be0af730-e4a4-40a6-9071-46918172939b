# 字幕交付校审台

字幕交付校审台面向公共文化视频发布团队，用于管理无障碍字幕从项目建档、结构化修订、自动质量校验、问题整改、独立人工复核到不可变冻结的完整交付流程。冻结时系统生成确定性清单和带唯一验证码的交付凭据，并可在浏览器中重新计算摘要、核验当前存储内容与凭据是否一致。

同一工作台还提供项目队列组合筛选与阶段汇总、无修订草稿的交付规则修订、字幕提交前质量预检、修订父子差异与问题覆盖定位、问题批量处置、完整复核历史和退回依据对照，以及冻结前逐项就绪检查。顶栏可直接使用凭据编号或验证码检索冻结交付物，无需预先选择项目。

服务仅依赖 Go 标准库。业务数据默认保存在 `./data`，由 `snapshot.json` 快照和 `audit.jsonl` 摘要链审计日志组成。写入采用进程内互斥、临时文件同步和原子替换；所有变更命令使用 `expectedVersion` 防止过期写入，并通过 `idempotencyKey` 保证重试安全。

## 构建

```bash
go build ./cmd/server
```

## 运行

```bash
go run ./cmd/server -addr=127.0.0.1:19081 -data=./data
```

浏览器打开 `http://127.0.0.1:19081`。监听地址可通过 `-addr` 指定；未传入时默认使用 `127.0.0.1:19081`。也可以设置 `PORT` 为端口号，服务会绑定 `127.0.0.1:<PORT>`。显式传入 `-addr` 时以命令行参数为准。

## 测试

运行全部单元与集成测试：

```bash
go test ./...
```

运行真实回环 HTTP 全流程自检：

```bash
go run ./cmd/server -addr=127.0.0.1:19081 -selfcheck
```

自检使用临时数据目录，经 HTTP API 完成建档、问题修订、处置记录、替代修订、独立复核、冻结签发与凭据验证，并在成功后自行退出。

## 业务约束

- 字幕修订不可变，新提交通过 `parentRevisionID` 保留完整谱系。
- 草稿交付规则只能在首次字幕修订前整体更新，仍使用 `expectedVersion` 和 `idempotencyKey` 保护写入。
- 自动校验检测时间码越界、片段重叠、阅读速度、空文本、断行和说话人标记问题。
- 质量预检与正式提交使用同一规范化和校验链，但预检不创建修订、审计事件或幂等记录。
- 问题批量处置全有或全无，并且一次批量操作只增加一个项目版本和一条审计事件。
- 提交者不能审核自己的修订；批准必须同时通过语言准确性和无障碍适配。
- 正式冻结会在当前版本重新执行与只读就绪面板相同的项目状态、活动修订、自动校验、活动修订问题和最新批准决定检查。
- 冻结项目拒绝后续业务变更，交付凭据可用编号或验证码独立验证。
- 凭据报告分别核验项目与修订绑定、修订内容摘要、冻结清单摘要、验证码和追加审计摘要链。
